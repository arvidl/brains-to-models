# BrainWeb teaching inputs

These two compressed NIfTI volumes are bundled so notebooks 14b and 14c work
without another repository or a data download. Together they occupy 9,246,603
bytes (about 9.25 MB). They are the original normal digital phantom's simulated
noise-free T1 image and discrete tissue labels, not patient scans or tumour data.
Tumour states and noisy observations are generated by this repository's code.

The canonical source is [BrainWeb](https://brainweb.bic.mni.mcgill.ca/brainweb/),
including its [normal anatomical model](https://brainweb.bic.mni.mcgill.ca/anatomic_normal.html).
The [manifest](manifest.json) records source aliases, byte sizes and SHA-256
digests. These NIfTI copies match those previously distributed in the companion
`brainweb_fisher_kpp` repository at commit
`81ecd42e6f37692a711208caa8d24361904f7e65`. That is provenance, not a runtime
dependency. Neither volume is resampled or modified here.

The image and labels have matching native dimensions 181 × 217 × 181 and 1 mm
spacing. The loader checks hashes and physical geometry before explicitly
sampling the grid for the teaching calculations. The complete 1 mm volumes are
included so students can choose a different sampling interval.
