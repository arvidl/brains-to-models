# Final presentation

The final 30-minute *From Brains to Models* presentation is available as a [PowerPoint file](From%20Brains%20to%20Models_20261029_1030.pptx): the 29 October 2026 version, with 25 slides and a file size of 78.1 MiB. On GitHub, open the file and use the download control.

This is an unchanged copy of the reviewed deck. Earlier decks, Beamer sources, presentation generators and rehearsal material remain in the separate private development repository.

The separate [slide-by-slide syllabus companion](../paper/syllabus.pdf) provides
25 teaching pages with thumbnails, two reading paths, predictions and exercises,
expanded mathematical explanations and a glossary covering both paths;
slides 18–20 guide the coupled model in [14d](../code/notebooks/14d_coupled_tumour_growth.ipynb).
The [perspective paper](../paper/main.pdf) retains the thematic discussion and
technical appendices.

[Tentative solutions to the syllabus exercises](../paper/syllabus-solutions.pdf)
works through both paths for all 25 slides, with biological explanations,
mathematical derivations and interpretation checks.

The [slide-to-resource guide](resources.md) maps the 29 October deck to local notebooks and versioned external demonstrations. The [resource manifest](resources.json) records its checksum and source versions. Notebook [13](../code/notebooks/13_verified_growth_model.ipynb) provides the numerical verification walkthrough; [14a–14c](../code/notebooks/README.md#interactive-growth-controls) add interactive density, anatomical and parameter-recovery lessons. Their code and normal BrainWeb inputs are included here, independently of the original external demonstrations.

This repository is public at `arvidl/brains-to-models`; the presentation is available without repository membership.
